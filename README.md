# Linux Study Notes

These are my personal study notes from learning Linux and using it in development and system administration. They bring together the commands, concepts, and practical examples I want to keep as a clear reference.

## About these notes

I am building this collection as I study Linux. It starts with the terminal and filesystem, then covers permissions, users, processes, packages, Bash, networking, storage, services, security, and routine system maintenance.

Examples use common GNU/Linux tools. Package management examples use APT where a distribution-specific example is needed. Commands, service names, file locations, and available tools can differ between distributions, so each example states its assumptions where relevant. Practice administrative commands in a virtual machine or a system you control.

## Core topics

- Navigate the filesystem and manage files from the command line
- Search and inspect text with standard utilities
- Understand permissions, ownership, users, groups, and sudo
- Inspect processes, jobs, services, logs, and system resources
- Install software with a distribution package manager
- Use Bash variables, quoting, functions, scripts, and control flow
- Combine commands with pipes, redirection, and text processing
- Connect to systems and diagnose basic network issues
- Understand disks, filesystems, mounts, boot, scheduled tasks, and backups
- Apply practical security and troubleshooting habits

## How to use these notes

Start with the command line and filesystem chapters, then work through one topic at a time. Try each command in a safe practice environment, read its manual page, and check the result before combining it with other commands. Commands that change system configuration or delete data are called out clearly.

The examples focus on concepts shared across Linux systems. Distribution-specific commands are labeled so you can adapt them to your own system.
